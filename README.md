# NextDay Digital

Website source for https://nextdaydigital.digital (Sites origin: https://nextdaydigital.anthonyalfano157.chatgpt.site).

## Local preview

Run `python -m http.server 8765 --directory dist`, then open http://localhost:8765.

No build step or dependency installation is required. Edit `dist/index.html`, `dist/style.css`, and `dist/app.js`. The landscape, auto and bakery HTML pages are fictional portfolio examples with AI-generated images.

## Collaboration

Create a branch, commit your changes and open a pull request. Luciano has write access. GitHub changes do not automatically publish to the live website; Anthony deploys approved changes through the existing Sites project.

The inquiry form opens an email draft in the visitor's mail app; it does not store submissions.

Only public website files belong here. Do not commit outreach data, sender records, API keys or hosting credentials.
